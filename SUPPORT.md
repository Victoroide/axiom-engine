# Support

## Questions

GitHub Discussions is not enabled for this repository. If you have questions about using or configuring AxiomEngine, open an issue using the question template at [github.com/Victoroide/axiom-engine/issues/new/choose](https://github.com/Victoroide/axiom-engine/issues/new/choose).

## Bug Reports

Report unexpected service behavior by opening an issue using the bug report template at [github.com/Victoroide/axiom-engine/issues/new/choose](https://github.com/Victoroide/axiom-engine/issues/new/choose). Blank issues are disabled.

When filing a bug report, include:
- A concise description of the observed behavior and the expected result.
- Minimal steps to reproduce the issue, such as a sample request payload or command line invocation.
- Environment details: service version or commit SHA, Go version, operating system, architecture, and deployment method (container image, release archive, or source build).
- Relevant log output or error responses with credentials, tokens, and sensitive data removed.

## Security Vulnerabilities

Do not open public GitHub issues for security vulnerabilities. Report security issues privately through the process documented in [SECURITY.md](SECURITY.md).
